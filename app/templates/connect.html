Claude

claude.ai en la web y Claude Desktop

{{ widget('yes', ' (web, Desktop y móvil)') }} {{ icon('user') }}Todos los planes · Free: 1 conector personalizado

  1. Abre claude.ai (o Claude Desktop) y ve a Customize › Connectors.

  2. Pulsa + Add › Add custom connector.

  3. Escribe el nombre Lextor, pega tu URL y pulsa Continue.

    {{ urlchip() }}

  4. En Authentication elige No sign in y pulsa Add.

  5. En el chat, pulsa + (abajo a la izquierda) o escribe /, entra en Connectors y activa Lextor.

{{ icon('monitor') }}

¿Usas el móvil? Las apps de Claude para iOS y Android usan los conectores que añades en la web: añádelo una vez en claude.ai y aparecerá también en el móvil, con el lector incluido.

{{ icon('user') }}

Planes Team y Enterprise: un propietario (Owner) lo añade en Organization settings › Connectors › Add › Custom › Web. Después, cada miembro lo conecta en Customize › Connectors › Connect.

{% if has_token %}

Ojo: si la organización usa tu URL personal, todos guardarán en tu biblioteca. Para un conector compartido, cada persona debería usar su propia URL.

{% endif %}

Los nombres de los menús están en inglés; si usas Claude en otro idioma pueden aparecer traducidos.

{# ChatGPT ──────────────────────────────────────── #}
{{ mono('Ch', 'tr') }}

ChatGPT

chatgpt.com, como plugin con servidor MCP propio

{{ widget('yes') }} Business · Enterprise · Edu Pro: solo lectura Plus y Free: sin confirmar
{{ icon('alert') }}

Depende de tu plan. En Business, Enterprise y Edu los servidores MCP propios funcionan por completo. En Pro solo se permiten herramientas de lectura, así que tu IA podrá consultar textos pero probablemente no crearlos. En Plus y Free no está confirmado que se puedan añadir.

  1. Abre chatgpt.com/plugins.

  2. Pulsa + y elige Add custom MCP server.

  3. Nombre: Lextor. En Server URL pega tu URL.

    {{ urlchip() }}

  4. En autenticación elige No authentication y marca I understand and want to continue.

  5. Pulsa Create as a plugin e instálalo.

  6. En cualquier chat, escribe @ y elige Lextor.

{{ icon('shield') }}

ChatGPT te pedirá confirmación antes de usar las herramientas que guardan datos (crear o cambiar textos). Las de solo lectura se usan sin preguntar.

{{ icon('settings') }}

¿No ves esa página? En versiones anteriores la opción estaba en Settings › Apps › Advanced settings › Developer mode: actívalo y añade la app desde ahí con la misma URL y sin autenticación.

Gemini

App de Gemini, Gemini CLI y Antigravity

{{ widget('unknown') }} App: solo EE. UU., +18, cuenta personal, en inglés

App de Gemini

  1. Ve a Settings › Connected Apps › Custom apps.

  2. Pulsa Add a custom app, pega tu URL y pulsa Next.

    {{ urlchip() }}

  3. En el chat, escribe @ seguido del nombre de la app para usarla.

{{ icon('alert') }}

Por ahora Google limita las apps personalizadas a cuentas personales de mayores de 18 años en EE. UU. y con Gemini en inglés. Tampoco hemos podido verificar que acepte servidores sin inicio de sesión como Lextor: si no te funciona, usa Claude o ChatGPT.

Gemini CLI y Antigravity

{{ icon('terminal') }}Para usuarios avanzados
{{ widget('no') }}

Desde el 18 de junio de 2026, Gemini CLI solo funciona con cuentas de empresa o con clave de API.

  1. Con Gemini CLI, añádelo desde la terminal:

    {% if has_token %} {{ snip('gemini mcp add --transport http -H "Authorization: Bearer {TOKEN}" -s user lextor {BASE}/mcp', 'Terminal') }} {% else %} {{ snip('gemini mcp add --transport http -s user lextor {URL}', 'Terminal') }} {% endif %}

  2. O edita ~/.gemini/settings.json a mano:

    {% if has_token %}{% set t %} { "mcpServers": { "lextor": { "httpUrl": "{BASE}/mcp", "headers": { "Authorization": "Bearer {TOKEN}" } } } } {% endset %}{% else %}{% set t %} { "mcpServers": { "lextor": { "httpUrl": "{URL}" } } } {% endset %}{% endif %} {{ snip(t, '~/.gemini/settings.json') }}

  3. En Antigravity, usa ~/.gemini/config/mcp_config.json:

    {% if has_token %}{% set t %} { "mcpServers": { "lextor": { "serverUrl": "{BASE}/mcp", "headers": { "Authorization": "Bearer {TOKEN}" } } } } {% endset %}{% else %}{% set t %} { "mcpServers": { "lextor": { "serverUrl": "{URL}" } } } {% endset %}{% endif %} {{ snip(t, '~/.gemini/config/mcp_config.json') }}

Si el archivo ya tiene mcpServers, añade solo la entrada "lextor".

Clientes que solo admiten servidores locales

{{ icon('terminal') }}Avanzado

Preguntas y problemas

{{ icon('eye-off') }}No veo el lector dentro del chat{{ icon('chevron-down', 'cx-chev') }}

No todos los asistentes muestran apps interactivas (Claude Code o la app de Gemini, por ejemplo). Tu IA siempre te da un enlace al texto: ábrelo y tendrás el mismo lector, con todas las funciones.

En Claude, comprueba también que Lextor esté activado en ese chat (botón + › Connectors).

{{ icon('alert') }}Dice «token no válido» o no conecta{{ icon('chevron-down', 'cx-chev') }}

Seguramente la URL se regeneró o se copió incompleta. Copia de nuevo la URL del paso 1 (o pulsa Regenerar) y actualízala en el conector de tu asistente.

{{ icon('file-text') }}¿Funciona con textos largos?{{ icon('chevron-down', 'cx-chev') }}

Sí. Tu IA envía los textos largos por partes automáticamente: crea el texto con el principio y añade el resto en varios envíos. Si se detiene a mitad, dile «continúa».

{{ icon('shield') }}¿Qué se guarda? ¿Es privado?{{ icon('chevron-down', 'cx-chev') }}

Lextor guarda los textos que crea tu IA (original, traducciones y notas) y, de la conexión, solo la fecha del último uso y el nombre del cliente. No tiene acceso a tus conversaciones: únicamente recibe lo que tu IA envía al usar sus herramientas.

Los enlaces públicos usan un identificador aleatorio imposible de adivinar: solo puede abrir un texto quien tenga su enlace.

{{ icon('log-out') }}¿Cómo desconecto Lextor?{{ icon('chevron-down', 'cx-chev') }}

Elimina el conector en los ajustes de tu asistente (en Claude, Customize › Connectors). Para cortar el acceso en todas partes a la vez, pulsa Regenerar en el paso 1: la URL antigua deja de funcionar al instante.

{% if not has_token %}
{{ icon('user') }}¿Necesito una cuenta?{{ icon('chevron-down', 'cx-chev') }}

No para probar: con la URL pública tu IA puede crear textos, pero solo se guardan como enlaces públicos. Con una cuenta tienes tu URL personal y una biblioteca con tus proyectos.

{% endif %}
